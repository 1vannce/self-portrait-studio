# Prompt Templates

The reusable prompts for AI-assisted development now live in
[`prompt/`](../prompt/README.md). Choose the template that best matches the
task; the prior general implementation brief is now
[`prompt/feature.md`](../prompt/feature.md).

The prompt library complements—not replaces—
[`AGENT_INSTRUCTIONS.md`](./AGENT_INSTRUCTIONS.md) and
[`ARCHITECTURE.md`](./ARCHITECTURE.md), which remain the source of truth for
project constraints.
